# 🎓 EduVault – Your Journey Starts Here

### A Smart Student Profile & Academic Management System

EduVault is a web-based student management platform designed to digitally organize and manage students' academic and professional information in one centralized location.

The platform allows students to securely access and manage their personal profiles, academic credentials, certificates, internship details, and project progress.

Our goal is to simplify student data management and provide an organized digital platform that supports students throughout their academic journey.

---

## 🚀 Project Objectives

* Digitally maintain student academic and personal information.
* Provide secure, individual student login accounts.
* Store certificates and academic credentials digitally.
* Maintain internship and project information.
* Simplify student information management for colleges.
* Support students in tracking their academic and professional growth.

## ⚙️ Installation & Setup

Follow these steps to run EduVault locally.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/yaswanthkappa-25/Eduvault.git
```

**Step 2: Navigate to the Project Directory**

```bash
cd Eduvault
```

**Step 3: Create a Virtual Environment**

```bash
python -m venv venv
```

**Step 4: Activate the Virtual Environment**

Windows:

```bash
venv\Scripts\activate
```

**Step 5: Install Django**

```bash
pip install django
```

**Step 6: Apply Database Migrations**

```bash
python manage.py migrate
```

**Step 7: Run the Development Server**

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
